# Lab 1 – Virtual Machine Setup

## Objective
Build and perform the basic setup of four operating systems as Virtual Machines using VMware Workstation 17 Pro.

## What I Did
- Installed VMware Workstation 17 Pro (Broadcom)
- Created and configured four VMs using the naming convention `<FirstInitial><Lastname>-<OS>`

## Virtual Machines Created

| VM Name | Operating System | RAM | CPUs | Storage |
|---------|-----------------|-----|------|---------|
| DForcho-Win11 | Windows 11 Pro | 4 GB | 4 | 25 GB |
| DForcho-WinSRV22 | Windows Server 2022 (Standard w/ Desktop Experience) | 4 GB | 4 | 25 GB |
| DForcho-Ubuntu | Ubuntu Client | 4 GB | 4 | 25 GB |
| DForcho-UbuntuSRV | Ubuntu Server | 4 GB | 4 | 25 GB |

## Configuration
- **Network Adapter:** NAT
- **Hardware Compatibility:** Workstation 25H2
- **USB Controller:** Present
- **Sound Card / Display:** Auto detect
